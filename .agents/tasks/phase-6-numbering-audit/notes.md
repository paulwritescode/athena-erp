## What changed
- **`internal/numbering`** (new): series patterns (`{yyyy}`, `{yy}`, `{mm}`, one `{#####}` counter), scope = pattern with date tokens filled in, counter rows in `athena_number_counters`. `Next` locks the row (`ForUpdate` through the dialect) in the caller's transaction (gap-free); `NextIndependent` takes a number in its own transaction (may skip, never blocks); `Ensure` creates the row first so first-time callers do not race.
- **`internal/audit`** (new): append-only `athena_audit_log` with `prev_hash`/`hash`, locked chain head `athena_audit_heads`, `Append` in the change's transaction, `Verify` (missing, reordered, edited, inserted rows, deleted tail, optional `seq:hash` anchor), `Rows`. Hash input is length-prefixed and the change list is hashed in canonical re-encoded form.

- **Audit rows** for create, update, delete, submit (with `name` change), cancel, amend (successor and copied lines). `ListRecordHistory` now returns old/new values, request ID, source, seq and hash (`RecordEvent`, `FieldChange`).

## Open points for the owner
1. One audit chain means every audited write waits for the head row lock until commit. Per-type or partitioned chains are the alternative if write throughput matters.
2. Anchoring is manual: export `seq:hash` from `athena audit verify` and pass it back with `--anchor`. No scheduled daily digest.
3. Audit rows hold field values, with no masking of sensitive fields yet (P8 permissions, masking later).
4. "Privileged roles" for manual names (spec 24.3) cannot be enforced until P8.
5. The parent picker offers submitted documents, but the server then refuses new lines on them with a toast. Excluding non-draft parents from the picker would be a small follow-up if wanted.
6. A manual name equal to a future series number makes that submit fail (a gap-free series must not skip); the message names the clash.
7. Series scope is the date only; company and branch scopes wait for P11. Other naming forms (`by_field`, `expr`, `hash`, `prompt`, `singleton`) are not built.
8. The brief said `--project`; the repository standard since P2a is `--workspace`, so the new commands use that.
