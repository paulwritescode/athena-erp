# ADR-NNNN: Short decision title

- **Status:** Proposed | Accepted | Rejected | Superseded
- **Date:** YYYY-MM-DD
- **Decision owner:** Name or “not assigned”
- **Related decisions:** ADR/D IDs

## Context

What problem or choice requires a decision? Include constraints and evidence. Separate facts from assumptions.

## Options considered

1. Option A — advantages, costs, risks.
2. Option B — advantages, costs, risks.

## Decision

State only what was actually decided. If proposed, say what feedback or evidence is still needed.

## Consequences

Describe effects on product behavior, implementation, operations, compatibility, security, and future choices.

## Revisit when

Name the evidence or condition that would justify changing this decision.
